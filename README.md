感谢大家一直以来对本项目的关注、使用与支持。

自即日起，本项目不再进行任何形式的开发与维护，包括但不限于：

- 不再开发新功能或发布新版本
- 不再修复问题或更新依赖
- 不再提供安装包和技术支持
- 不再保证历史版本能够正常运行

本分支仅用于保留项目公告，不代表项目仍在持续运营或维护。

## 温馨提示

- 已经保存到本地的重要资料，请及时做好额外备份。
- 请勿从第三方渠道下载所谓的新版、修复版或其他衍生版本。
- 对于第三方修改、分发或使用所产生的问题，本项目无法提供支持。
